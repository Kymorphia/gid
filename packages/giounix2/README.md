# D binding for the GioUnix library - Portable API for dynamically loading modules

This [Dub](https://dub.pm/) sub-package of [giD](https://gid.dub.pm) provides a [D language](https://www.dlang.org) binding to the [GioUnix 2.0](https://gtk.org) library.

| **Dub Package**          | [gid:giounix2](https://code.dlang.org/packages/gid%3Agiounix2)                   |
