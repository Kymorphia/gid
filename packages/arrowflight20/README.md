# D binding for Apache ArrowFlight 20.0 GLib - Universal columnar format and multi-language toolbox

This [Dub](https://dub.pm/) sub-package of [giD](https://gid.dub.pm) provides a [D language](https://www.dlang.org) binding to the [ArrowFlight 20.0](https://arrow.apache.org) library.
