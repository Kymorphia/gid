# D binding for Apache Parquet 19.0 GLib - column-oriented data file format

This [Dub](https://dub.pm/) sub-package of [giD](https://gid.dub.pm) provides a [D language](https://www.dlang.org) binding to the [Parquet 19.0](https://github.com/red-data-tools/parquet-glib) library.
