# D binding for the GLibUnix library - Portable API for dynamically loading modules

This [Dub](https://dub.pm/) sub-package of [giD](https://gid.dub.pm) provides a [D language](https://www.dlang.org) binding to the [GLibUnix 2.0](https://gtk.org) library.
