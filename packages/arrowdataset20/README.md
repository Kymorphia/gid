# D binding for Apache ArrowDataset 20.0 GLib - Universal columnar format and multi-language toolbox

This [Dub](https://dub.pm/) sub-package of [giD](https://gid.dub.pm) provides a [D language](https://www.dlang.org) binding to the [ArrowDataset 20.0](https://arrow.apache.org) library.
